BiscuitBake-Off

Teacher screen. Open a kitchen, put this on the projector, and let the class race for the perfect biscuit.

How a round works

  1. Students go to the game link and type the room code.
  2. You press Start. Everyone bakes through 6 stations at once, with the same oven and the same dough.
  3. Watch the live leaderboard, then ring the bell to crown the best biscuits.

The game server naps when nobody's playing, so the first open of the day can take up to a minute.
