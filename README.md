# Biscuit Bake-Off

Six baking stations, one shot. Can you make the perfect buttermilk biscuit?

**Play:** https://ostromaj.github.io/biscuitmaker/

## The six stations

| Station | What you do | What it changes on your biscuit |
| --- | --- | --- |
| Measure the flour | Hold to pour, let go at the line (flour keeps falling a moment) | Rise and tenderness |
| Cut in the butter | Tap cubes to chop them to pea size before they melt | Rise |
| Stir in the buttermilk | Tap when the spoon is in the green zone, 5 times | Tenderness (cracks) |
| Fold the layers | Match the arrows fast | Flaky layers and rise |
| Cut the biscuits | Stamp the moving cutter on each circle | Roundness |
| Bake | Pull them out when they match the golden goal | Color |

Each station scores 0–100, so a biscuit is out of 600. **570+ is The Perfect Biscuit.**

## Using it in class

- **Start baking** gives a fresh random kitchen every time.
- **Today's class challenge** gives everyone the exact same kitchen for the whole day, so students can compare scores fairly. Have them call out their scores or post them in Classroom.
- Each student's personal best and today's challenge best are saved in their own browser.

Works with mouse, touchscreen, or keyboard (Space / Enter and arrow keys).

## How it's built

Plain HTML, CSS and JavaScript in `docs/`, served by GitHub Pages. No build step, no server, no accounts.
